⚙ Ajustes de conexión

La ruta histórica de posiciones de EMT es editable por si EMT cambia el endpoint. La API actual puede requerir una ruta/version distinta.
Crear las credenciales
→ Registrarse en MobilityLabs Madrid → Portal de desarrolladores → Documentación / API de EMT → OpenAPI EMT
Según la documentación de MobilityLabs, al crear una aplicación se obtienen el x-ClientId y el passKey.
Importante sobre este HTML
Las credenciales se guardan únicamente en localStorage de este navegador. No se envían a ningún servidor propio. Si el navegador bloquea las peticiones por CORS, necesitarás servir este HTML desde un pequeño backend/proxy; el panel permite conservar la misma configuración.
