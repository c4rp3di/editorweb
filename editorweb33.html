🚀 Publicar (GitHub Pages)
Completa estos 4 pasos una sola vez. Después, publicar es un solo botón.
1️⃣ Cuenta de GitHub

Si no tienes cuenta, créala gratis (solo pide un email).

Abrir registro de GitHub ↗
2️⃣ Repositorio

Crea un repositorio nuevo y público donde vivirán tus páginas. El nombre lo eliges tú.

Crear repositorio ↗
3️⃣ Activar GitHub Pages

En ese repositorio: Settings → Pages → "Build and deployment" → Deploy from a branch → rama main, carpeta / (root) → Save.

(rellena primero usuario y repositorio arriba para que este botón te lleve al sitio exacto)
4️⃣ Token de acceso

Crea un token que solo pueda escribir en ese repositorio:

  1. Pulsa el botón de abajo.
  2. En "Repository access" elige Only select repositories → tu repositorio.
  3. En "Permissions" → "Repository permissions" → Contents → ponlo en Read and write.
  4. Pulsa "Generate token" al final y copia el token (empieza por github_pat_).
Crear token ↗
🌐 Publicar (Netlify)
Solo 2 pasos: cuenta y token. La app crea el sitio por ti.
1️⃣ Cuenta de Netlify

Si no tienes cuenta, créala gratis.

Abrir registro de Netlify ↗
2️⃣ Token de acceso personal

User settings → Applications → Personal access tokens → New access token.

A diferencia del de GitHub, este token no se puede limitar a un solo sitio — da acceso a toda tu cuenta de Netlify. Bien para uso personal, pero consciente de ello.
Crear token ↗
